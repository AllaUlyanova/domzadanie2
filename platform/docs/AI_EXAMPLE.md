# Пример проверки домашнего задания

## Вход

```json
{
  "studentId": "demo-student",
  "exerciseId": "demo-ex-48-27",
  "answer": { "type": "MATH_EXPRESSION", "value": "74" }
}
```

## RAG-контекст (фрагмент учебника)

```
[1] стр. 12 № 1
Сложение двузначных чисел с переходом через разряд...
```

## Промпт (сокращённо)

Система: Пушок, 3 класс, только факты из учебника.  
Пользователь: условие, правильный ответ 75, ответ ученика 74, контекст RAG.
